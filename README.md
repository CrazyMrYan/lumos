# Lumos 🪄

**Lumos** is an AI-enhanced Markdown transformer that turns a single Markdown source into stunning slides, mind maps, and static websites instantly.

## Core Philosophy

- **Single Source of Truth**: One `.md` file, infinite views.
- **AI-Powered**: Auto-summarize for slides, auto-layout for mind maps.
- **Client-First**: Privacy-focused, local processing, instant rendering.

## Tech Stack

- **Editor**: Vditor
- **Slides**: Reveal.js
- **Mind Map**: Markmap
- **Framework**: Next.js (App Router) + React
- **Styling**: Tailwind CSS

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```
